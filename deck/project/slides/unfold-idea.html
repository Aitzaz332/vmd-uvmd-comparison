Unfolding: an iterative algorithm becomes a network

Iterative solver

repeat n = 1..500:
x ← T(x; θ)

One operator T, one fixed θ (α, τ), many repetitions until convergence.

Unfolded network

x₁ = T(x₀; θ₁)
x₂ = T(x₁; θ₂)
… x_N = T(x_{N−1}; θ_N)

The same operator, but N copies (N small) with their own learnable θ_n.

  • Each iteration becomes a layer; fixed depth N replaces “until convergence”
  • Hyperparameters become weights that gradient descent can tune
  • Origin: LISTA, which unfolded ISTA for sparse coding (Gregor and LeCun, 2010)
The structure of the algorithm is kept, so the network stays interpretable: every layer is still one step of the original method.
