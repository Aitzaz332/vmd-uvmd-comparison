ADMM turns it into three closed-form updates

Mode update

û_k = ( f̂ − Σ_{i≠k} û_i + λ̂/2 ) / ( 1 + 2α(ω − ω_k)² )

Centre frequency

ω_k = ∫₀^∞ ω |û_k(ω)|² dω / ∫₀^∞ |û_k(ω)|² dω

Dual ascent

λ̂ ← λ̂ + τ ( f̂ − Σ_k û_k )

  • The mode update is a Wiener-like filter centred on ω_k; α sets how narrow it is
  • ω_k is the power-weighted mean frequency of the mode, positive half spectrum
  • All updates run in the FFT domain, so the method is global and non-causal
Standard VMD (Dragomiretskiy and Zosso, 2014). In our benchmark tau is 0, so the multiplier stays at zero and the data constraint is only enforced through the mode update.
