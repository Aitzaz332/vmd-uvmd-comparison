What UVMD trains, and what it does not

Trained

α_k, K values

  • Bandwidth penalty per mode, through softplus
  • Shared by all layers
  • Initialised at 2000

Trained

λ̂_n, one per layer

  • Complex vector of length 2T (T = signal length)
  • Replaces the dual variable
  • Initialised at 0

Not trained

ω_k

  • Recomputed from û_k in every layer
  • Starts on a fixed uniform grid, 0.5·k/K
  • No weight of its own

Both trained parameters enter only the mode update. The frequency update has none, so ω can change only through û_k.

The released code allocates N+1 rows for lambda, the last one is never used. Alpha is a single vector of K values reused in every layer.
