How an unfolded algorithm is trained

1

Truncate

Keep N iterations, N = 1 or 2 here

2

Parametrise

Pick hyperparameters to learn, one set per layer

3

Define a loss

Score the output of the last layer

4

Backpropagate

Gradients flow through all layers; Adam updates the parameters

5

Fix and deploy

Freeze the weights, run N layers on new signals

Trade

Speed for guarantees

Far fewer steps, but no convergence guarantee and tuned to the training data

Training is end to end: the loss only sees the final layer, but its gradient reaches every layer’s parameters.
