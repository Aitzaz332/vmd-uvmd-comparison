UVMD: one layer is one VMD sweep

Input f

Mirror, FFT, keep the positive half: f̂₊

→

Layer 1

α_k, λ̂₁

→

Layer N

α_k, λ̂_N

→

Modes u_k

Inverse FFT; loss on Σ_k û_k

û_k = ( f̂₊ − Σ_{i≠k} û_i − λ̂_n/2 ) / ( 1 + softplus(α_k)(ω − ω_k)² )

ω_k = Σ ω |û_k|² / Σ |û_k|² (positive half, k ≥ 1)

Layer n sweeps through the K modes (Gauss-Seidel), then recomputes every ω_k from the new spectra. Mode 0 stays at DC. Written as in the released code.

Source: Ahmad, Wesemann, Waschkowski, Khalid, arXiv 2509.00703, and the released code (OsamaAhmad369/MAGN, uvmd.py). Equation form is the code’s; the paper differs slightly, see the paper-versus-code slide.
