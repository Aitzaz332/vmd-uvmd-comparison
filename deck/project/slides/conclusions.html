Conclusions and next steps

What we found

  • UVMD reconstructs better than VMD at the same depth on every signal, with 1 or 2 layers instead of hundreds of iterations
  • It does not separate better: at best on par with untrained VMD-N, below converged VMD
  • Reconstruction error is no evidence of separation
  • ω barely moves on traffic and synthetic, but moves a lot on CWRU

Next steps

  • Add a separation term (bandwidth or orthogonality) to the loss
  • Give ω a trainable path: learned initial grid or a filter on the spectrum
  • Ablate: train α only, then λ̂ only
  • Test on forecasting with causal windows
  • Run the full traffic protocol

Traffic results come from a bounded run (100 / 20 / 30 nodes). Code, tables and figures: repository vmd-uvmd-comparison.

The next-step ideas are proposals, not results. They would be implemented as separate files, leaving the upstream UVMD code untouched.
